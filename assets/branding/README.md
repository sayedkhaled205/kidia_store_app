# Google sign-in mark

`google-g.png` is the unmodified full-color Google G supplied by Google for
sign-in buttons, downloaded on 2026-10-25.

- Asset: https://developers.google.com/static/identity/images/g-logo.png
- Usage: https://developers.google.com/identity/branding-guidelines

Keep it bundled locally and preserve its aspect ratio and colors. The shared
`AuthScreen` uses this asset in both the mobile application and CMS preview.
Do not replace it with a font glyph, a theme-tinted icon, or a network image.
This file is a Google brand asset; use remains subject to Google's branding
guidelines.
